# Overview

Pairit is a platform for running human‑AI experiments. Author a single YAML file, publish, and collect data. Use built‑in components, or [upload your own HTML](components/html.md).

### Key features

1. Simple, declarative configs
2. Rich components (survey, matchmaking, chat, live workspace)
3. Upload your own HTML UI, wired to experiment data
4. Human–human and human–AI setups
5. Real‑time collaboration and chat
6. Server‑hosted AI agents (keys stay on the server)
7. Randomization and treatment assignment
8. Data export in CSV, JSON, and JSONL formats
